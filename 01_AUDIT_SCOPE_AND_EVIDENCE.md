# Audit Scope and Evidence

## In scope

- Repository inventory, architecture and functionality.
- Static code inspection and non-destructive baseline attempts.
- Target architecture for a sustainable local-first agent Markdown framework.
- Gap scoring, risk register, production tasks and sprint proposal.
- Current official documentation for Claude Code, Codex, Cursor, GitHub Copilot and Windsurf.

## Out of scope / unavailable

- Git history, deployed application, production data and credentials.
- Successful dependency installation/build in this environment.
- Browser runtime, model calls and client-specific smoke tests.
- Compliance certification and penetration testing.

## Evidence classes

- `source-inspected`: directly supported by repository source.
- `static-analysis`: supported by a local deterministic scan.
- `primary-source`: supported by current official vendor documentation.
- `unverified`: not successfully tested.
- `contradicted`: implementation or evidence conflicts with the claim.
