# PRR-022 — Add optional provider-backed extractor plugin

- Priority: **P2**
- Size: **L** (relative estimate, not a commitment)
- Dependencies: PRR-002, PRR-009

## Objective

Define an extractor interface for local rules or an approved LLM, with structured output validation and no dependency of the compiler core on a provider.

## Acceptance criteria

- [ ] Deterministic local extractor remains default
- [ ] LLM output must validate before use
- [ ] Provider failure falls back without data loss

## Verification

- [ ] Add or update automated fixtures.
- [ ] Run typecheck, tests and production build.
- [ ] Record evidence in the release report.

## Done when

The acceptance criteria pass and no unresolved P0 regression is introduced.
