# PRR-006 — Create versioned runtime adapter registry

- Priority: **P0**
- Size: **L** (relative estimate, not a commitment)
- Dependencies: PRR-002

## Objective

Move runtime behavior to data-backed adapters with official source, verified date, supported files, import rules, limits and deprecation status.

## Acceptance criteria

- [ ] Claude, Codex, Cursor, Copilot and Windsurf adapters have fixtures
- [ ] Each adapter records source and verified date
- [ ] Unsupported semantics produce explicit warnings

## Verification

- [ ] Add or update automated fixtures.
- [ ] Run typecheck, tests and production build.
- [ ] Record evidence in the release report.

## Done when

The acceptance criteria pass and no unresolved P0 regression is introduced.
